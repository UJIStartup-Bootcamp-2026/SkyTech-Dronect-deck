# Dronect — Pitch deck (HTML)

Abrir `index.html` en el navegador (doble clic). No necesita servidor.

- Navegación: rueda/scroll, flechas ← → ↑ ↓, AvPág/RePág, Inicio/Fin.
- Tecla **N**: muestra u oculta las notas del orador.
- Pantalla completa: F11.
- La tipografía (Inter) se carga de Google Fonts; sin internet usa la del sistema y todo sigue funcionando.
- Pendiente (marcado en ámbar): quién presenta, roles del equipo y contacto final.

Subir `index.html` a la raíz del repositorio SkyTech-Dronect-deck. No tocar la carpeta `MCP/`.
